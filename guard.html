Oversell Guard, run live

This is the Python script from Exception 1, running in your browser on ten fake sell orders. Change a quantity, press Run, and watch the rules decide.

Starting Python 3.12 in the browser
  1. 1Read the books

    Five CSVs: settled positions, pending activity (unsettled buys, ACATS in and out), corporate actions, advisor history and today's orders.

  2. 2Work out what can be delivered

    For each sell, in time order: settled − pledged + confirmed buys by T+1 − ACATS out − sold earlier today.

  3. 3Apply rules R1 to R8

    Fixed rules block, hold or warn. A blocked order does not use up the position, so a later sell is checked against what is really left.

  4. 4Report

    Writes alerts.json and alerts.md, drafts the advisor messages, and exits with code 1 if anything was blocked, so a scheduler can page someone.

Input: today's sell orders, Nov 5, 2026

Settlement is T+1, Nov 6. Edit any quantity, or try a change below.
